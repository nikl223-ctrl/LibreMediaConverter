Was wird hier tatsächlich bewiesen?

Eine Webseite kann Dateien dynamisch von einem GPU-losen Server laden und die Grafik auf PC/Xbox/Mobilgerät selbst rendern, sofern die jeweilige Browser-Grafik-API verfügbar ist. Die Spieldaten sind im HTTP-Browsercache gespeichert, und der Spielstand wird separat auf dem Server gesichert. Dieses Demo enthält **kein** ETS/ATS und keine Windows-Spiel-EXE. Native Spiele brauchen eine Browser-Portierung ihrer Engine.
