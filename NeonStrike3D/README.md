# NEON STRIKE 3D

A self-contained, mobile-first, **real-time 3D first-person survival shooter**, made with **Godot 4.5.2**. The arena, enemy armor, weapon, neon decoration, effects and sounds are generated using code; no commercial assets or external services required.

## Game

- Procedural 3D cyber-arena, weapon view model, directional lighting, fog and emissive materials.
- Enemy waves with different **Sentinel** and **Brute** types.
- Automatic rifle, laser tracers, damage, explosions and auto-reload.
- Pickup healing, score, enemy AI and escalating wave sizes.
- Dual touch-stick scheme with independent **move, look, fire, dash, reload, pause**.
- Desktop controls: WASD / arrow keys, mouse aiming, mouse button fire, Space dash, R reload, Escape pause.
- Orientation: landscape. Offline, no account or permissions.
- Optimized for ARM64 Android phones, including Galaxy S24 Ultra. FPS is a target rather than a measured guarantee.

## Android APK through GitHub Actions

This project lives inside the `neon-strike-3d` branch of `nikl223-ctrl/LibreMediaConverter` under the `NeonStrike3D` directory. The existing converter's `main` branch is untouched.

The GitHub Actions workflow `.github/workflows/neon-strike-3d.yml` builds an ARM64 Android debug APK on branch pushes and manual workflow dispatch. The APK is generated by downloading matching Godot editor/export templates and running `godot --headless --export-debug`.

1. Open the **Actions** tab of the repository.
2. Select **Neon Strike 3D APK**.
3. Open the newest **green** run.
4. Under **Artifacts**, download **NeonStrike3D-Android-APK**.
5. Extract the ZIP and install `NeonStrike3D.apk` on your Android phone. Android may require permission to install APKs from the browser/files app.

> The APK is a **debug-signed** sideload build for testing, not a Play Store release. GitHub requires sign-in to download Actions artifacts. If the workflow fails, check the failed step logs; don't treat a repository link as proof that the APK exists.

## Local development

Open `NeonStrike3D/project.godot` in the Godot 4.5.2 editor and press F6/F5 to test. Android export requires matching export templates, Android SDK, and JDK 17.

## Source structure

- `project.godot`, `main.tscn` — Godot project and startup scene.
- `scripts/game.gd` — first-person game, procedural environment, enemies, collision, projectiles, sfx.
- `scripts/hud.gd` — adaptive HUD and multitouch Android controls.
- `export_presets.cfg` — ARM64 Android debug package configuration.
- `.github/workflows/neon-strike-3d.yml` — APK build & artifact upload.

No telemetry, trackers or internet permission.
